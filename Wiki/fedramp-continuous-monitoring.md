# FedRAMP Continuous Monitoring (ConMon)

> [!abstract] Summary
> FedRAMP Continuous Monitoring (ConMon) is the ongoing process by which a CSP demonstrates that its authorized system maintains its security posture after the initial ATO. It is governed by CA-7 and requires regular scanning, monthly reporting to the AO, annual assessments by a 3PAO, and real-time POA&M tracking of open findings.

## Governing Control

> [!quote] NIST 800-53 Rev5 — CA-7 (Continuous Monitoring)
> "Develop a system-level continuous monitoring strategy and implement continuous monitoring in accordance with the organizational continuous monitoring strategy that includes: a. Establishing the following system-level metrics to be monitored; b. Establishing monitoring frequencies for metrics and for assessments supporting monitoring; c. Automating the monitoring process to the degree possible; d. Evaluating system security and privacy posture [per FedRAMP: at least monthly]; e. Correlating and analyzing security and privacy-related information generated by assessments and monitoring; f. Responding to the results of the analysis of security and privacy-related information; and g. Reporting the security and privacy status of the system to designated organizational officials."
> — [[Sources/FedRAMP/fedramp-moderate-baseline#CA-7|CA-7]]

## ConMon Deliverables Calendar

| Deliverable | Frequency | Recipient |
|---|---|---|
| Vulnerability scan results (OS/infra) | Monthly | AO |
| Vulnerability scan results (web apps) | Quarterly (Moderate), Monthly (High) | AO |
| POA&M update | Monthly | AO |
| Inventory update | Monthly | AO |
| Security impact analysis (significant changes) | As needed | AO |
| Annual security assessment (3PAO) | Annually | AO / FedRAMP PMO |
| Penetration test | Annually (High) | AO / FedRAMP PMO |

## ConMon Process Flow

```
Monthly Cycle:
  1. Run authenticated vulnerability scans
  2. Triage new findings against SLAs
  3. Update POA&M (new items, closed items, delayed items)
  4. Update system inventory
  5. Submit deliverables to AO by agreed deadline
  6. AO reviews and approves or requests remediation

Annual Cycle:
  1. 3PAO conducts security assessment (SAR update)
  2. Penetration test (High baseline)
  3. Review and update SSP
  4. AO issues updated ATO letter
```

## Significant Change Notification

Any significant change to the authorized system boundary requires notification to the AO before implementation, and may require a 3PAO assessment.

> [!info] What Constitutes a Significant Change
> - Adding new services or components to the authorization boundary
> - Changes to authentication mechanisms
> - Changes to network architecture
> - Software/hardware changes that affect the security posture
> Significant changes must undergo security impact analysis per CA-7 and CM-3.

## AWS Tools for ConMon

> [!example] AWS ConMon Toolstack
> | Tool | ConMon Role |
> |---|---|
> | **Security Hub** | Aggregated compliance dashboard — maps to NIST 800-53 / FedRAMP |
> | **AWS Config** | Config compliance findings feed into monthly reports |
> | **Amazon Inspector** | Vuln scan results for EC2, ECR, Lambda |
> | **CloudTrail** | Audit log — evidence of monitoring activity |
> | **GuardDuty** | Threat detection findings |
> | **AWS Audit Manager** | Automates evidence collection for FedRAMP controls |

> [!tip] Audit Manager for ConMon
> AWS Audit Manager has a built-in **FedRAMP Moderate** framework that maps controls to AWS evidence sources. It can auto-collect Config, CloudTrail, Security Hub, and IAM evidence, dramatically reducing manual ConMon effort.

## FedRAMP 20x ConMon Changes

FedRAMP 20x is redesigning ConMon to be machine-readable and automated.

> [!info] FedRAMP 20x Collaborative Continuous Monitoring
> - CSPs will attest to control effectiveness via machine-readable formats
> - Agencies can access real-time authorization data instead of waiting for monthly reports
> - 3PAO role shifts from periodic assessments to ongoing spot-checks and validation
> See: [[Sources/FedRAMP/fedramp-20x-collaborative-continuous-monitoring]]
